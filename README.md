# HomeLens

Plataforma de inteligencia inmobiliaria para España: modelos de precios de vivienda, pronóstico de series temporales y web interactiva.

## Estado

En desarrollo.

## Estructura

- `data/`: datos crudos y procesados (no versionados)
- `notebooks/`: exploración y análisis
- `src/`: código fuente
- `tests/`: pruebas
- `reports/`: informes y figuras
- `docs/`: documentación
